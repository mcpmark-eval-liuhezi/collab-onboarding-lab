# Collab Onboarding Lab

Welcome! This repository is the landing zone for new collaborators joining this project. Use it to learn how we work together, and to get comfortable with the collaboration basics before touching production code.

## House rules

These rules keep our work predictable and reviewable. They apply to everyone, including (especially) the maintainer.

1. Respond within one business day — when someone mentions you, reviews your code, or asks a question, acknowledge or answer it within one business day.
2. Never force-push the default branch — the default branch's history is shared and immutable; rewrite requests can only happen on your own feature branches.
3. All changes go through pull requests — no direct commits to the default branch; every change, however small, gets reviewed via a pull request.

## What's in this repo

- `README.md` — this file: orientation and the house rules above.
- `docs/first-week.md` — your week-one checklist. Start there.

When you're ready, look for the pull request titled **Add escalation policy** — that's your first assignment.

# First Week Checklist

Your goal for week one is to get oriented, not to ship features. Work through the items below in order and check them off as you go.

1. [ ] Read the `README.md`, especially the **House rules** — make sure you understand all three.
2. [ ] Clone this repository locally, create a scratch branch off the default branch, and confirm you can push and open a throwaway pull request.
3. [ ] Review the pull request titled **Add escalation policy** (`ESCALATION.md`) and leave at least one review comment on it.
4. [ ] Get familiar with the issue tracker: find `Onboarding task: review the escalation policy`, link it to the pull request review you just did, and comment with what you learned.
5. [ ] Meet the team: introduce yourself in the team channel and figure out who your go-to person is for code, infra, and scheduling questions.
6. [ ] Pick one small "good first issue" style improvement (typo, clearer doc wording) and open a pull request for it end-to-end, following the house rules.
7. [ ] Do a dry run of the escalation path from `ESCALATION.md` on paper: who would you ping first, and how would you reach them after hours?
